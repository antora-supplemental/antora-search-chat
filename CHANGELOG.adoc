= Changelog

All notable changes to this project will be documented in this file.

The format is based on https://keepachangelog.com/en/1.1.0/[Keep a Changelog],
and this project adheres to https://semver.org/spec/v2.0.0.html[Semantic Versioning].

== [Unreleased]

== [0.1.10] - 2026-10-17

=== Fixed

* **Scope dropdown hidden behind the doc mast:** scope menu, collapsed popover, Lunr results, and Ask panel now use a top-layer z-index (`--adt-search-top-z: 200`); paired with Valentus lifting `.adt-site-navbar` above `.adt-doc-mast` inside the sticky header, so search menus paint on top of everything.

=== Added

* **Floating dock placement** (`placement: dock`): fixed bottom dock — rounded outer box with a Keyword / Semantic / Chat capability strip (disabled status checkboxes, no emojis), stacked scope-above-input card inside; scope menu, Lunr results, and Ask panel open *upward* above the dock. Navbar remains the default placement.
* **Capability levels config:** `semantic_enabled` / `semanticEnabled` (or `semantic_backend_url`) exposes the semantic level in the runtime payload (`levels: { keyword, semantic, chat }`) and the capability strip. The hybrid semantic engine remains a separate track; this is its UI/config seam.
* **Enter = chat query:** typing still searches on keystroke (Lunr); pressing Enter in the search field submits the query to Ask when chat is enabled.

=== Changed

* Placeholder copy: main label is *Semantic Search* when the semantic level is enabled, else *Search* (*… or Ask* appended when chat is on). The muted note now reads *(Chat unavailable)* instead of *(AI mode not configured)*.
* Stacked search layout released: context selector above the input (`.adt-search-compound--stacked`); ARCHITECTURE and compound diagram updated.
* README: canonical hub GitHub topics URL → `docs.antora-supplemental.org/docs/hub-github-topics/`.

== [0.1.6] - 2026-10-17

=== Fixed

* **`/` and `?` shortcuts:** call Valentus `window.adtRevealSiteChrome()` before opening Search/Ask so scroll-away navbar + mast peek back into view for typing.

== [0.1.5] - 2026-10-16

* Read `searchChat` overrides from `@antora-supplemental/facto-stack` pack config when search-chat is not a separate playbook require.
* Treat Lunr as present when the playbook requires facto-stack (compose pack registers Lunr before search-chat).

== [0.1.4] - 2026-09-09

* *Change:* Scope closed face drops the *Component*/*Version* kind prefix and shows the selected label only. Replace the native `<select>` with a static hierarchy tree menu (`All docs` → current component → versions, with *current* on the page version).
* *Docs:* Extract the compound-control layout into canonical Mermaid source and ship explicit Themed SVG standalone-adaptive and host artifacts with deterministic generate/check tooling.
* *Docs:* Consumer discovery topic is the bare repo name `antora-search-chat` (not `uses-*`); SemVer tag pins. Fan-out via skills `update-consumers` + `antora-extension-consumers`.

== [0.1.3] - 2026-08-01

* *Fix:* Theme toggle light↔dark — opaque omnibox chrome (`.adt-search-compound`, scope slot, collapse toggle / popover, Ask panel) now transitions `background-color` / `color` / `border-color` with the page instead of snapping. Adds `--adt-search-theme-transition` aligned with Valentus `--adt-transition`.

== [0.1.2] - 2026-07-25

* Search dropdown edges, scope dual-tone labels, collapse-to-icon, scope caret mask, and related omnibox polish (see Valentus theme changelog for integration notes).
